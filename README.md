## Vista previa

A continuación se muestran algunos ejemplos de los mensajes personalizados que puede generar **CustomDeathMessages**.

Los mensajes están diseñados para reemplazar las muertes tradicionales de Minecraft por textos más descriptivos y variados, manteniendo información relevante como el nombre del jugador y la causa de muerte. Además, utilizan colores para mejorar su identificación dentro del chat.
